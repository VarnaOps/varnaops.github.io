Mission

Make atlas-scale single-cell annotation reproducible, accessible, and trustworthy — so any lab can map its cells against the best available references and get publication-ready answers.

Reference atlases hold hard-won biological knowledge. Our job is to make that knowledge reusable — for every dataset, on everyday hardware.

The bottleneck we work on

Single-cell biology is generating data faster than any lab can interpret it. The hard part is no longer producing cells — it is turning them into reliable, comparable answers: which cell types are present, how they shift in disease, and how this dataset relates to everything measured before. Community reference atlases encode an enormous amount of that knowledge. VarnaOps exists to put it to work on your data, consistently and at scale.

How we approach it

We build references organ by organ from open, properly licensed data, train models that map new data into them, and return predicted cell types, confidence, markers, differential expression, and a shareable report. Three principles guide the engineering:

  • Reproducibility as a feature. Every reference is versioned and every run is provenance-stamped, so a result can be traced, explained, and re-run — the foundation for using these answers in a publication or a regulated setting.
  • Built to scale down, not just up. The pipeline is designed to handle atlas-scale data on a single commodity GPU, so capability isn't gated by a compute budget.
  • Standards over bespoke. We stay close to the field's accepted methods, labels, and statistics, so results are interpretable and comparable rather than locked into one tool's conventions.

Where we're headed

A growing library of high-quality, benchmarked references across tissues — each one a reusable, citable foundation — and an annotation engine simple enough that the analysis is the easy part. If a particular tissue matters to your work, tell us; it helps us decide what to build next.
